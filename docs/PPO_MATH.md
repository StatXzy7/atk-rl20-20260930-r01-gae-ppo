# PPO 核心训练步的数学说明：向量化自动重置下的轨迹边界

本文推导 `ppo_audit/` 中实现的两类掩码与损失，并精确说明 λ 与价值函数
有偏时的估计性质。记号：缓冲区按时间展开为 `T` 条记录，第 `t` 条记录
包含 `(s_t, a_t, r_t, final_obs_t)` 以及采集时旧策略的 `V_old(s_t)`、
`log π_old(a_t|s_t)`。`valid_t` 标记真实步与填充步；`terminated_t` 为
真正的终止（到达终止状态）；`truncated_t` 为仅被时间限制截断。

向量化环境在 `terminated` 或 `truncated` 之后**立即自动重置**，因此缓冲
区里第 `t+1` 条记录可能已经属于新 episode。这是全部边界问题的来源。

## 1. 两个掩码的推导

### 1.1 TD bootstrap 掩码 `b_t`

单步 TD 误差本应是

```
δ_t = r_t + γ · V(s_{t+1}) − V(s_t)
```

其中 `V(s_{t+1})` 仅当 `s_{t+1}` 存在时有意义：

- **真终止**（`terminated_t = 1`）：`s_{t+1}` 不存在，回报在 `r_t` 处结束，
  必须 `b_t = 0`。注意此时缓冲区里的 "next observation" 是**新 episode
  的初始观测**（自动重置的产物），它的价值与已结束的 episode 毫无关系。
- **时间截断**（`truncated_t = 1`）：episode 并非真正结束，只是被时间上限
  切断；被切断时刻的状态仍有明确定义的价值。因此允许 `b_t = 1`，但必须
  用**截断前最终观测** `final_obs_t` 的价值 `V^f_t` 来 bootstrap，而
  不是自动重置后新 episode 的初始观测价值。
- **批次末尾未终止**：采样窗口结束但 episode 未结束，与截断同理，
  `b_t = 1`，用最后一条记录的 `final_obs` 价值 bootstrap。
- **填充步**：`b_t = 0`，不产生任何 TD 误差。

综上：

```
b_t = valid_t ∧ ¬terminated_t
δ_t = r_t + γ · b_t · V^f_t − V_old(s_t)        （仅对 valid_t 定义）
```

实现：`compute_boundary_masks` 返回的 `bootstrap_mask`。

### 1.2 GAE 递推连接掩码 `c_t`

GAE 的递推形式为

```
A_t = δ_t + γλ · c_t · A_{t+1}
```

`c_t` 回答的问题是：**第 `t+1` 条记录是否仍属于第 `t` 条记录所在的
episode？** 只有在同一 episode 内，把 `A_{t+1}` 累加进 `A_t` 才有意义。

- 真终止后：下一条记录是新 episode，`c_t = 0`。
- **时间截断后**：虽然 δ 允许 bootstrap（见 1.1），但缓冲区里下一条记录
  已经是自动重置后的新 episode，优势**不能递推过去**，`c_t = 0`。
  这正是"截断可以 bootstrap 但不能连接"的含义：截断步自身的 TD 目标里
  含有 `γ·V^f`，而它之前的步不能透过它继续累加未来优势。
- 批次末尾：没有下一条记录，`c_{T-1} = 0`。
- 跨越填充：`c_t = 0`（填充两侧不属于同一连续轨迹）。

综上：

```
c_t = valid_t ∧ valid_{t+1} ∧ ¬terminated_t ∧ ¬truncated_t   (t < T−1)
c_{T-1} = 0
```

实现：`compute_boundary_masks` 返回的 `connection_mask`。

### 1.3 完整递推

```
A_t = 0                                              （t 为填充步）
A_t = δ_t + γλ · c_t · A_{t+1}                       （t 为有效步，从后往前）
R_t = A_t + V_old(s_t)                               （λ-回报，价值回归目标）
```

`R_t` 使用**未归一化**优势；归一化只作用于策略项（见 §3）。

## 2. 手算验证轨迹（tests/test_gae.py）

以下四条轨迹覆盖了全部边界类型，期望值均为手算结果。

### 轨迹 1：真终止（γ=1, λ=1）

`r=[1,2,3]`, `V=[0.5,0.5,0.5]`, 第 2 步真终止，`next_values[2]=7.7`
（故意放入垃圾值，正确实现绝不读取）。

```
δ = [1+0.5−0.5, 2+0.5−0.5, 3+0−0.5] = [1, 2, 2.5]
A = [1+2+2.5, 2+2.5, 2.5] = [5.5, 4.5, 2.5]
R = A + V = [6, 5, 3]   （恰好是 reward-to-go）
```

### 轨迹 2：时间截断（γ=0.5, λ=1）

`r=[1,1]`, `V=[0.4,0.6]`, 第 1 步截断，`V^f_1 = 2.0`。

```
δ_1 = 1 + 0.5·2.0 − 0.6 = 1.4      δ_0 = 1 + 0.5·0.6 − 0.4 = 0.9
A_1 = 1.4                           A_0 = 0.9 + 0.5·1·1.4 = 1.6
R   = [2.0, 2.0]                   （= 截断处的折扣回报含 bootstrap）
```

### 轨迹 3：批次截断（γ=1, λ=1）

`r=[1,1,1]`, `V=[0,0,0]`, 无任何结束标志，`next_values[2]=1.5`。

```
A_2 = 1+1.5 = 2.5   A_1 = 1+2.5 = 3.5   A_0 = 1+3.5 = 4.5
```

### 轨迹 4：同一缓冲区内连续两个 episode（γ=1, λ=1）

`r=[1,1,2,2,2]`, `V=[0.1,…,0.5]`，第 1 步真终止（`next_values[1]=9.9`
为 reset 观测价值，必须被忽略），第 4 步截断（`V^f_4=3.0`）。

```
episode A: δ_1 = 1−0.2 = 0.8,  δ_0 = 1+0.2−0.1 = 1.1
           A_1 = 0.8,  A_0 = 1.1+0.8 = 1.9
episode B: δ_4 = 2+3.0−0.5 = 4.5,  δ_3 = 2+0.5−0.4 = 2.1,  δ_2 = 2+0.4−0.3 = 2.1
           A_4 = 4.5,  A_3 = 6.6,  A_2 = 8.7
```

测试另外验证：episode B 单独计算得到的优势与缓冲区内的完全一致
（无跨边界泄漏）。

## 3. 损失与更新

设 `N = Σ valid_t`，所有期望均为**仅对有效步**求均值：

```
ratio_t = exp(log π_θ(a_t|s_t) − log π_old(a_t|s_t))
L_π   = −(1/N) Σ min(ratio_t·Â_t, clip(ratio_t, 1−ε, 1+ε)·Â_t)
L_V   = (1/N) Σ (V_θ(s_t) − R_t)²
H     = (1/N) Σ H(π_θ(·|s_t))
L     = L_π + c_v·L_V − c_e·H
```

- `Â_t` 为**仅在有效步上**归一化（总体标准差，ddof=0）的优势，只用于
  策略项；`R_t = A_t^{raw} + V_old(s_t)` 用未归一化优势。
- `log π_old`、`Â`、`R` 在进入更新前一次性算好并**冻结**，更新只移动
  网络参数（`build_training_batch` / `ppo_update` 的两阶段结构）。
- clip 生效处（ratio 触及 1±ε 且被截断分支选中）目标对参数为常数，
  策略梯度为 0；ratio = 1±ε 处不可微，有限差分核验须避开折点。

边界情形的定义行为：

- **只有 1 个有效步**：样本均值即其自身，中心化后 Â = 0，策略项无信号
  （不臆造尺度）；价值与熵项照常。
- **0 个有效步**：所有损失为 0、所有梯度为 0，优化器步进为无操作，
  参数不变。

## 4. λ、偏差与方差：不能笼统说"GAE 无偏"

GAE 是优势 `A^π` 的**有偏**估计，除非价值函数恰好精确。精确表述：

- **λ = 0**：`A_t = δ_t`，单步 TD。偏差直接来自 `V` 的误差：若
  `V ≠ V^π`，则 `E[δ_t | s_t, a_t] = A^π(s_t,a_t) + γ·E[b_t(V(s')−V^π(s'))]`，
  偏差依赖于动作（通过后继状态），**会污染策略梯度的期望**。方差最低。
- **λ = 1**：`A_t = Σ γ^k r_{t+k} (+γ^T b V^f) − V(s_t)`，即（含边界
  bootstrap 的）蒙特卡洛回报减基线。此时
  `E[A_t | s_t, a_t] = Q^π(s_t,a_t) − V(s_t) = A^π + (V^π − V)(s_t)`：
  估计偏差 `V^π(s_t) − V(s_t)` **只是状态的函数**。作为基线，它不改变
  策略梯度的期望（`E_a[∇log π(a|s)·b(s)] = 0`），只影响方差。方差最高。
- **0 < λ < 1**：介于两者之间；λ 越小结越依赖自举，偏差中依赖动作的
  成分越大。λ 是偏差–方差权衡旋钮，不是"无偏开关"。
- 仅当 `V = V^π` 精确成立时，任意 λ 的 GAE 才是 `A^π` 的无偏估计；
  函数逼近下这从不成立。因此本实现与文档只声称：λ=1 时偏差不污染
  策略梯度期望（状态基线性质），λ<1 时估计本身有偏。

## 5. 失败反例（tests/test_counterexample.py）

把自动重置后的 reset 观测价值 `V_reset` 错当 `final_obs` 价值：

- 真终止步：δ 多出 `γ·V_reset`，并沿 `(γλ)^k` 向前传播到同 episode
  的每一步。轨迹 4 中 `V_reset = 9.9`：`A_1` 从 0.8 变成 10.7，
  `A_0` 从 1.9 变成 11.8。
- 截断步：用 `V_reset` 替代 `V^f` 使 δ 损失 `γ·(V^f − V_reset)`，
  整个被截断 episode 的优势整体偏移。
- 符号翻转：单步 episode，`r = −1`（惩罚性终止），`V_reset = 5`：
  正确优势 `−1`，错误优势 `+4`——智能体会被训练去**主动追求**
  惩罚性终止状态。
